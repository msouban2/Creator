# Aaina — Meta App Review submission pack

Everything you need to move the Instagram integration from **Development/Testing** to
**Live/Production** — **without** publishing to the Play Store.

- App type: **Instagram API with Instagram Login** (standalone Instagram Business Login)
- Permissions to request **Advanced Access** for:
  - `instagram_business_basic`
  - `instagram_business_manage_insights`
- Public URLs (hosted on the deployed admin site):
  - Privacy Policy: `https://<your-admin-domain>/privacy`
  - Data Deletion: `https://<your-admin-domain>/data-deletion`
  - (Default Render domain is likely `https://aaina-admin.onrender.com`)

Files in this folder:
- `01-review-descriptions.md` — copy-paste text for each permission in App Review
- `02-screencast-script.md` — exact steps to record the demo video
- `03-checklist.md` — the full go-live checklist (your side + settings)
