# Screencast script (record this for App Review)

Meta reviews Instagram permissions by **watching a screen recording** of the actual login +
data usage. No Play Store listing is needed — a recording of your APK (or the web build) is
accepted. Aim for **60–120 seconds**, clear and unhurried.

## Before you record
- Use a **real Instagram professional (Business/Creator) account** you control as the test
  creator. Add it under App → Roles → **Instagram Testers** and accept the invite in that
  Instagram account (so it works while the app is still in Development mode).
- Install the Aaina APK on your phone (or open the web build), and be logged in as a creator.
- Use a screen recorder that captures taps (Android built-in screen recorder is fine).
- Make sure the Instagram **consent screen** clearly shows in the recording — reviewers must
  see the permissions being granted.

## The recording — step by step
1. **Show the app.** Open Aaina. Briefly show the home/campaigns screen so it's clear this is
   a real app with a purpose (creator–brand marketplace).
2. **Go to Profile.** Tap the Profile tab.
3. **Start the connect.** Tap **"Connect Instagram"**.
4. **Instagram Login.** The Instagram login page opens. Log in (or continue) with the test
   Instagram professional account.
5. **Consent screen — pause here.** The permission screen appears requesting
   *instagram_business_basic* and *instagram_business_manage_insights*. Let it stay on screen
   for ~2 seconds so it's clearly captured, then tap **Allow / Authorize**.
6. **Return to Aaina.** The browser bounces back to the app.
7. **Show the data being used.** On the profile / performance screen, show the now-populated
   **follower count** and the **insights** (reach, profile views, average engagement). This
   demonstrates exactly how each permission's data is used.
8. **(Optional but strong) Show the brand side.** Log into the admin dashboard and open the
   creator's performance card to show the aggregated figures a brand sees. This proves the
   business purpose.
9. **(Optional) Show revocation.** Return to the app profile and show the **Disconnect
   Instagram** option, demonstrating the user can revoke access.

## Tips to pass first time
- Narrate on-screen or add captions naming each permission as it's used.
- Don't cut away during the consent screen — that's the single most important frame.
- Keep it to the connect + display flow; don't wander into unrelated features.
- Upload the video as unlisted/public (YouTube/Drive) if the dashboard asks for a link, or
  attach the file directly if it allows upload.
